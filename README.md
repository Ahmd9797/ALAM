# تطبيق مكتب إعلام شركة فاوري ذي قار

تطبيق متكامل لإدارة وعرض أعمال شركة فاوري في محافظة ذي قار.

## المميزات

- 📸 عرض الأعمال المنجزة في بانر متقلب
- 🎯 أحدث العروض والخصومات
- 💬 آراء الزبائن مع نظام موافقة المدير
- 🏗️ معرض المشاريع المنجزة (قبل/أثناء/بعد)
- 🛍️ قسم المنتجات (كاندنز، فاوري، دوراكس)
- 📞 طلب استشارة عبر وسائل التواصل

## التقنيات المستخدمة

- Flutter
- Firebase (Auth, Firestore, Storage)
