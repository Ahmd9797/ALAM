# موقع مكتب إعلام شركة فاوري ذي قار

موقع ويب متكامل لإدارة وعرض أعمال شركة فاوري في محافظة ذي قار.

## المميزات

- 🎨 واجهة مستخدم عربية احترافية
- 🔐 نظام مصادقة (مدير/مستخدم)
-  بانر متقلب للأعمال المنجزة
- 🎯 إدارة العروض والخصومات
- 💬 نظام آراء الزبائن مع موافقة المدير
- 🏗️ معرض المشاريع المنجزة
- 🛍️ قسم المنتجات (كاندنز، فاوري، دوراكس)
- 📞 روابط التواصل الاجتماعي

## التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (ES6+)
- Firebase (Auth, Firestore, Storage)
